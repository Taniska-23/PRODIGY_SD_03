# Contact Management System

## About the Project

This is a simple Contact Management System developed using Python. It allows users to add, view, edit, and delete contacts. The contact information is stored in a JSON file, so the data is saved even after the program is closed.

## Features

- Add new contacts
- View all contacts
- Edit existing contacts
- Delete contacts
- Store contacts in a JSON file
- Simple and user-friendly menu

## Technologies Used

- Python
- JSON

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python contact_management.py
```
